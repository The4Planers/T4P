# The4Planers — Final Portfolio

A responsive Scan to BIM / CAD to BIM / Revit portfolio built for GitHub Pages.

## Included in this final build
- Desktop, tablet and mobile responsive layout
- Premium welcome screen with T4P logo
- Fixed BIM base + draggable Point Cloud comparison slider (mouse + touch)
- Working favicon set: ICO, 16px, 32px, Apple Touch Icon and Android icons
- Project portfolio loaded from `assets/projects/projects.json`
- Four project case studies with optimized videos and image galleries
- Project detail modal with video, scope, delivery and project visuals
- WhatsApp and LinkedIn contact buttons
- Lightweight WebP images and compressed MP4 videos for easier GitHub Pages hosting

## GitHub Pages
Upload the **contents** of this folder to the root of the branch used by GitHub Pages. Keep the `assets` folder and its subfolders exactly as provided.

The project list is controlled by `assets/projects/projects.json`, so new project cards can be added later without redesigning the site.
