# The4Planers — Portfolio V1

A cinematic, GitHub Pages-ready portfolio prototype for The4Planers.

## Quick use
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to your GitHub Pages repository.
3. Commit changes.
4. Open your GitHub Pages URL.

No build step is required in this V1.
