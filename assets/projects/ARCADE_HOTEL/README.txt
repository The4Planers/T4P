ARCADE_HOTEL – The4Planers Project Page
=========================================
Files:
- index.html  -> project page
- style.css   -> responsive styling
- assets/     -> supplied point-cloud and BIM screenshots

HOW TO USE:
1. Upload the entire ARCADE_HOTEL_Website folder to your website.
2. If your existing site has a Projects folder, place this folder inside it.
3. Open index.html to view the project page.
4. Change the navigation paths (../index.html) if your main website uses another folder structure.
5. The contact buttons use info@the4planers.site.
